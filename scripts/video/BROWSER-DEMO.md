# Tabby — real browser film

The landing page now uses `public/demo/tabby-browser-demo.mp4`: 60 seconds, 1920×1080, H.264 at 30 fps, AAC instrumental audio, and English on-screen copy. A JPEG poster and a WebVTT description track accompany it. The earlier illustrated 15-second film remains available separately.

## What was captured

The actual installed Tabby side panel in Chrome for Testing, alongside public React documentation and a logged-out YouTube cat video. The goal was **Build a React login form**. These were real DeepSeek responses and real extension actions:

- React documentation classified as on track; the cat video classified as a possible distraction.
- Back to work returned to the React tab.
- From page generated a task draft with three steps and its source URL. The draft was reviewed and saved.
- AI suggested React Documentation and Distractions; confirmation created native Chrome tab groups.

This is an edited product film assembled from native window captures, with close-ups, cuts, held frames and condensed waits. The raw capture cadence is lower than the 30 fps motion-graphics output. It is not an uninterrupted screen recording or a latency benchmark. No model results, browser pages or extension controls were replaced with mock UI. Neither CopilotKit nor Ambiguous is represented as implemented in this film.

## Edit and render

The timeline and frame selection are in `scripts/render-browser-video.mjs`. Layout and camera movement are in `scripts/video/browser-demo.html`. The soundtrack is an original synthesized instrumental generated by `make-browser-soundtrack.py`; it contains no downloaded samples, third-party music or voiceover.

Raw frames and their timestamp index live in the git-ignored `artifacts/browser-demo/` directory. Historical capture filenames use `.png`, but the files contain JPEG data. To render on another machine, copy that capture directory (or extract it from the local handoff kit) into the same project-relative location. Credentials and browser profile data are not required or included.

With the project dependencies and Playwright Chromium installed, use Python 3 and an FFmpeg build containing `libx264`:

```sh
python3 scripts/video/make-browser-soundtrack.py
node scripts/render-browser-video.mjs --preview
TABBY_FFMPEG=/absolute/path/to/ffmpeg node scripts/render-browser-video.mjs
```

Omit `TABBY_FFMPEG` if `ffmpeg` is on PATH. `TABBY_CAPTURE_DIR` can override the raw capture directory. The renderer serves only explicitly selected local files and blocks network requests outside its temporary loopback origin. It performs no live AI calls and does not operate the recorded browser.

Review frames and the expanded edit list are written to `artifacts/browser-video-review/`. Product installation and extension ZIP instructions remain in the root README.
