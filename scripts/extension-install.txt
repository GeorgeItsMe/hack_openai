TABBY — A LITTLE MORE HEADSPACE

INSTALL IN CHROME

1. Unzip Tabby.zip.
   Mac: double-click the ZIP.
   Windows: right-click the ZIP, choose Extract All, then Extract.
   Keep the extracted Tabby folder somewhere permanent, such as Documents.

2. Open Chrome and paste this into the address bar:
   chrome://extensions
   Turn on Developer mode in the top-right corner.

3. Click Load unpacked in the top-left corner.
   Select the extracted Tabby folder containing manifest.json.
   Select the folder, not the ZIP file.

Click Chrome's puzzle-piece icon, pin Tabby, then click the Tabby cat.
Click Enable AI once to use the included DeepSeek assistance. No account, API key
or local server is needed. Review the short data disclosure before enabling it.
Add your first task or start a focus session. You're in.

KEEP THE FOLDER
Chrome loads Tabby from this folder. Keep it in the same place after installing.
If you see a manifest error, choose the inner folder that contains manifest.json.

WHAT'S READY
Tasks, projects, notes, saved links, tab search, duplicate cleanup and timers.
AI is included in this hackathon preview, with fair-use limits.
Optional Google and MCP connections still use separate companion setup.
The browser ZIP contains no server, API key or account credentials.

This is a manual-install preview, not a Chrome Web Store installation.
Chrome on a desktop or laptop is required. Managed computers may disable
Developer mode; ask your administrator if that option is unavailable.

Visual instructions: https://tabby-pi.vercel.app/ (choose Try Tabby)
