# Tabby

Работающее расширение Chrome Manifest V3: цель → контекст страницы → оценка AI → напоминание → возврат к работе. Русский и английский интерфейс. React, TypeScript, Node HTTP и GPT Tunnel.

**Статус поставки:** DeepSeek 3.2 (`deepseek-v3.2`) подключён к настоящему GPT Tunnel. Три живых запроса прошли: учебный материал — aligned, развлекательный — distracting, недостаточный контекст — unknown. Ключ хранится только в локальном `.env`. Сборка, 23 unit/protocol/HTTP теста и предыдущие 20 сценариев Chromium пройдены.


## Быстрое рабочее демо

```sh
npm run server    # отдельный терминал
npm run demo
```

`demo` открывает отдельный Chrome for Testing с установленным расширением, подключает локальный токен и проверяет две подготовленные страницы настоящим DeepSeek. После возврата к работе оставляет сеанс на паузе и боковую панель открытой. Нажмите «Продолжить» для демонстрации. Профиль находится в `.local/demo-chrome`; ваш основной профиль Chrome не меняется. Требуется установленный Playwright Chromium (`npx playwright install chromium`). Не запускайте второе демо с тем же профилем, пока первое окно открыто.

## Установка и запуск

Нужны Node.js 22.6+ (проверено на 24), npm, Chrome 120+.

```sh
npm ci
npm run setup
npm run build
npm run server
```

1. `setup` создаёт `.env` и `.local/pairing.txt` с правами `0600`. Существующий API-ключ не перезаписывается. Эти файлы исключены из Git.
2. Откройте `chrome://extensions` → **Режим разработчика** → **Загрузить распакованное расширение** → выберите **`dist/extension`**. Папка уже собрана; также доступен `dist/tabby-extension.zip`.
3. Закрепите и нажмите значок Tabby: откроется боковая панель.
4. В **Настройках** вставьте содержимое `.local/pairing.txt` в поле **Токен подключения**. Это отдельный локальный токен, **не API-ключ GPT Tunnel**.
5. Запишите `GPTUNNEL_API_KEY` в локальный `.env`. Перезапустите сервер. Нажмите **Подключить и проверить**.
6. Прочитайте описание передачи данных и включите **Разрешить анализ через AI**. Видимый текст включается отдельно; кнопка **Разрешить доступ к текущему сайту** запрашивает только его origin.
7. Введите цель/выберите задачу, длительность и нажмите **Начать фокус**. Через ~8 секунд на активной странице появится оценка, если AI подключён.

Сервер всегда слушает loopback `127.0.0.1:4318`, проверяет точный extension Origin и отдельный токен. Ключ провайдера хранится только на сервере. Публичный `key` в manifest нужен для стабильного ID расширения и не является секретом.

## Недорогой DeepSeek через GPT Tunnel

```dotenv
GPTUNNEL_API_KEY=
GPTUNNEL_BASE_URL=https://gptunnel.ru/v1
GPTUNNEL_MODEL=deepseek-v3.2
```

Выбран `deepseek-v3.2` — недорогая действующая модель из каталога, доступного вашему ключу. Этот же ID используется по умолчанию при пустом `GPTUNNEL_MODEL`. Перед запросом наличие модели проверяется по каталогу. Для замены явно задайте другой точный ID в `.env` и перезапустите сервер. В UI отображается выбранная модель; скрытой замены нет.

```sh
npm run models       # живой каталог доступных моделей
npm run test:live    # 3 настоящих, потенциально платных completion
```

`test:live` сохраняет `.local/live-report.json` с входными сценариями, моделью, ответами и возвращённым usage. Проверяет учебное и развлекательное видео на одном домене и страницу без контекста. Без ключа возвращает `AI_NOT_CONNECTED`. Проверка каталога не является доказательством успешного completion.

12 сентября 2026 изучены [Chat Completions](https://docs.gptunnel.ru/api/chat-completions/), [список моделей](https://docs.gptunnel.ru/api/models/), [автоматическая подмена снятых моделей](https://docs.gptunnel.ru/getting-started/deprecated-models/). GET `https://gptunnel.ru/v1/models` без ключа вернул **401 Unauthorized**.

Используется raw `Authorization: API_KEY`, без автоматического `Bearer`. Endpoint `/chat/completions`. Для выбранного DeepSeek используются `reasoning_effort: none` и лимит ответа 600 токенов (группы — 1500, итог — 900), чтобы сократить время и расходы. JSON проверяется на сервере; Responses API не используется. JSON валидируется Zod на сервере и повторно в расширении. Каталог, `Deprecation`, `x-model-served`, `warnings` и ответ `model` проверяются на подмену. При неправильной схеме действие не применяется. Возвращённые `total_tokens` и `total_cost` сохраняются даже при отклонённом структурированном ответе; отсутствие стоимости не трактуется как ноль. `total_cost` показывается в единицах провайдера.

## Возможности

- **Фокус:** 25/50/своя длительность 1–480 минут, цель и задача, пауза, продолжение, завершение; перерывы 1–120 минут. Отсчёт по timestamps; закрытие панели и остановка worker не сбрасывают состояние.
- **Контекст:** заголовок, очищенный URL, разрешённый видимый текст до 4 000 символов, задача, время страницы, недавние события, поправки. Наблюдение только в работающем сеансе при присутствии пользователя.
- **Оценки:** по делу / возможное отвлечение / недостаточно контекста, объяснение и один следующий шаг. Dwell ~8 секунд, coalescing, TTL-кэш 2 минуты, отмена запросов и проверки session/revision/page fingerprint.
- **Помощь:** последняя подходящая рабочая вкладка; конкретная поправка «Это по делу»; перерыв на 5 минут; следующий шаг AI. Один материал не разрешает целый домен. Изменившиеся/закрытые рабочие вкладки пропускаются.
- **Строгость:** мягкие напоминания либо обратимая шторка с поправкой, перерывом, остановкой и Escape. Страница, URL и формы не заменяются. Ошибка AI/связи снимает ограничение.
- **Возвращение:** карточка после окончания перерыва с целью, известными рабочими материалами и подтверждённым пользователем шагом. Факты отделены от предложений; работа возобновляется явно.
- **Задачи:** создание/редактирование, выделение через контекстное меню, AI-извлечение по нажатию, черновик до сохранения, источник, три статуса, выбор для фокуса. Дедлайн требует проверяемой абсолютной даты в исходном тексте.
- **Вкладки:** текущий список, поиск и переключение; AI-предложение с просмотром состава; настоящие группы Chrome после подтверждения. Изменение вкладки после предпросмотра отклоняет старое предложение. Дубликаты определяются по полному URL локально; закрываются только выбранные, при сохранении другого экземпляра. Активные/закреплённые вкладки защищены от закрытия дубликатов.
- **Статистика:** рабочие интервалы, категории, перерывы, отсутствие, паузы, напоминания, возвраты, подтверждённые готовые задачи и AI-итог. Время на сайте не называется доказанной продуктивностью.

## Проверки

```sh
npm run check
npm test
npm run build
npx playwright install chromium
npm run test:browser
npm run test:smoke
```

`test:browser` требует свободный порт 4318: остановите обычный сервер перед запуском. Тест создаёт отдельный временный профиль Chrome for Testing и локальный сайт на 44320, не меняет ваш основной Chrome. Ответы семантического adapter явно фиктивны, запросы в GPT Tunnel не отправляются. Отчёт — `artifacts/browser-test-results.json`. `test:smoke` не использует fake AI и проверяет финальный UI/native Side Panel. Матрица и фактические ограничения: [docs/TESTING.md](docs/TESTING.md).

## Веб-предпросмотр

```sh
npm run dev       # http://127.0.0.1:5173/focus.html
npm run preview   # собранный интерфейс: http://127.0.0.1:4180
```

Предпросмотр честно сообщает, что анализ страниц/управление вкладками требуют установленного расширения. Ручные задачи и таймер работают локально, данные предпросмотра и расширения раздельны. Сервер preview выдаёт только разрешённые HTML/JS/CSS; `.env` и серверные исходники недоступны. Существующий лендинг Tabby сохранён отдельно; описание Tabby находится в этом файле, чтобы не заменять README лендинга.

## Структура и ограничения

`src/extension/` — manifest, service worker, content script и React Side Panel. `src/shared/` — типы, privacy, схемы и движок времени. `src/server/` — Node HTTP и GPT Tunnel adapter. `dist/extension/` — готовая папка Chrome, без серверного кода и секретов. `scripts/`, `tests/`, `docs/` — сборка, проверки и документация.

При изменении `TABBY_PORT` также измените порт в `worker.ts` и CSP manifest, затем пересоберите. Обычный запуск использует 4318.

DeepSeek проверен живыми запросами; для повторного запуска нужен работающий локальный сервер. Видео/аудио, canvas, iframe и закрытый Shadow DOM не транскрибируются/не читаются. Текст извлекается из видимой прозы, без полей ввода и форм; автоматическая очистка не гарантирует распознавание всех секретов в произвольном тексте. Для чувствительных страниц используйте исключения. Chrome internal/Web Store и incognito не анализируются.

Chrome может задерживать alarms. При ненаблюдаемом промежутке более 75 секунд время консервативно относится к отсутствию, а не к просмотру. Обычное отсутствие обнаруживается Chrome idle через 60 секунд либо при уходе из Chrome. После полного перезапуска браузера сеанс ставится на паузу.

Шторка имеет lease 40 секунд; content script проверяет его каждые 3 секунды. Ошибка снимает её при получении; разрыв соединения обнаруживается фоновым запросом примерно каждые 30 секунд. Сон вкладки может задержать JavaScript. Escape доступен всегда: это добровольная помощь, не родительский контроль.

Лимиты локального хранения: 100 прошлых сеансов, 500 задач, 1 000 событий текущего сеанса, 30 рабочих материалов; кэш — 150 оценок. Очистка доступна в настройках. Прерванный запрос может уже быть оплачен; если usage не дошёл, стоимость не выдумывается.
