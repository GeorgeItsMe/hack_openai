# Разрешения и поток данных

| Разрешение | Зачем |
|---|---|
| `sidePanel` | Основной интерфейс рядом с текущей страницей |
| `storage` | Настройки, задачи, сеанс и статистика локально; доступ только trusted extension contexts |
| `tabs` | Заголовок/URL активной вкладки в сеансе; список текущего окна по нажатию; возврат к работе |
| `alarms` | Дедлайны и восстановление таймера после остановки worker |
| `idle` | Отдельный учёт отсутствия и остановка анализа при нём |
| `contextMenus` | «Создать задачу» из явно выбранного текста |
| `scripting` | Внедрение разрешённого content script для ограниченного текста и шторки |
| `activeTab` | Временный доступ к текущей вкладке после действия пользователя |
| `tabGroups` | Настоящие названия и цвета групп после подтверждения |
| `http://127.0.0.1/*` | Только локальный AI-сервер; Chrome host permissions не ограничивают порт, но адрес клиента и CSP фиксируют 4318 |
| Необязательные `https://*/*`, `http://*/*` | Декларируют возможные сайты. Реальный запрос разрешения — только на origin текущего сайта, по нажатию пользователя |

Нет `history`, `cookies`, `webRequest`, `debugger`, разрешений загрузки или отправки сообщений другим людям.

Перед анализом пользователь разрешает передачу цели, выбранной задачи, очищенных заголовков/URL, времени страницы, недавних событий и поправок через локальный сервер → GPT Tunnel → модель. Извлечение задачи и группировка запускаются только по нажатию. Полный URL остаётся локально для точных дубликатов; он не передаётся модели. Ссылки в задачах очищаются перед хранением.

По умолчанию чтение текста выключено. После отдельного разрешения читается до 4 000 символов отрисованной прозы в viewport, максимум 8 000 просмотренных text nodes. Исключаются формы, поля ввода, редактируемые элементы, скрытый текст, script/style и помеченные `data-private`/`data-sensitive` блоки. Не читаются значения полей, пароли, cookies, история браузера или файлы. Regex-очистка также маскирует типовые секреты, email, длинные номера и URL в тексте; это дополнительная защита, не гарантия обнаружения любого свободно написанного секрета. Чувствительные сайты следует исключить или не давать им доступ.

При очистке URL удаляются credentials, query и fragment; только валидный публичный YouTube `v` сохраняется, чтобы различать видео. Адреса без этого параметра различаются по названию/контенту и локальному отпечатку полного адреса. Не следует отправлять чувствительные сведения в самой формулировке цели.

Контент страницы — данные. Он не меняет инструкции, цель, разрешения или список действий. Модель возвращает ограниченную схему JSON. Нет исполнения AI JavaScript, команд, HTML или произвольных адресов из ответа. UI рендерит текст через React/textContent. Server-side key не попадает в prompt, ошибки, логи, storage расширения или сборку.

Сервер отвергает неверные Host, Origin и токен, проверяет размер тела и тип запроса, ограничивает параллельные/частые обращения. Exact extension ID вычисляется из публичного manifest key; этот публичный ключ сохраняет стабильный ID и не является секретом провайдера. Локальный токен генерируется криптографически и не входит в сборку. CORS не является единственной защитой: токен проверяется `timingSafeEqual`. Произвольный локальный процесс с доступом к `.env` находится за пределами данной модели защиты.

Отключение согласия отменяет текущие запросы и останавливает content scripts. Данные, уже полученные GPT Tunnel ранее, отозвать этим действием невозможно; срок хранения определяется провайдером. Изменение исключений очищает связанные активные материалы/черновики и историю событий страниц текущего сеанса, чтобы они не повторялись в новом запросе.
