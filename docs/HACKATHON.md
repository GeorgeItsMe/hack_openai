# Tabby — пространство для важного

Мы часто теряем фокус не из-за конкретного сайта, а из-за того, что забываем исходную цель. Учебный ролик и развлекательное видео могут жить на одном домене. Tabby помогает различать их в контексте текущей задачи.

Пользователь задаёт цель и запускает рабочий сеанс. Расширение учитывает активную страницу, разрешённый фрагмент текста, события сеанса и поправки пользователя. Модель через GPT Tunnel предлагает оценку и один следующий шаг. Пользователь может вернуться к материалам, исправить оценку или сделать перерыв. После перерыва сохраняются цель, рабочие вкладки и подтверждённый шаг.

Смысловые решения отделены от механики: AI объясняет и предлагает, а TypeScript считает время, хранит задачи и выполняет разрешённые Chrome API. Строгий режим обратим, при ошибке соединения ограничение снимается. Группы и закрытие точных дубликатов требуют явного действия пользователя.

**Стек:** Chrome MV3, Service Worker, Side Panel, TypeScript, React, Zod, esbuild, Node HTTP; GPT Tunnel Chat Completions. Для прототипа пользователь выбрал недорогой DeepSeek 3.2 (`deepseek-v3.2`), точный ID проверен по доступному каталогу. **Доказательства:** автоматические тесты таймера/схем/безопасности и интеграционные проверки в настоящем Chromium. DeepSeek подключён: реальные ответы на три контрольных сценария получены; без доступного сервера интерфейс показывает «AI не подключён».

Нет аккаунтов, синхронизации, публикации в магазине или обращения к полной истории браузера. Локальный API-ключ не попадает в расширение. Прототип подходит для демонстрации управляемого пользователем помощника по вниманию, без обещаний измерять его продуктивность.
