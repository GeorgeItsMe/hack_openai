# Демо на две минуты

До выступления: установить `dist/extension`, запустить сервер, локально подключить ключ/токен, проверить каталог и `npm run test:live`. Включить согласие на передачу данных. Открыть рабочую страницу про авторизацию React и развлекательную страницу. Для чтения текста/строгой шторки отдельно разрешить нужные сайты. Если ключ не подключён, объявить, что AI-часть не демонстрируется; таймер и ручные функции доступны без неё.

| Время | Что показать | Что сказать |
|---|---|---|
| 0:00–0:20 | Русская боковая панель. Цель «Изучить авторизацию в React и собрать пример», 25 минут, начало | «Tabby ориентируется на текущую цель. Наблюдение начинается только после старта.» |
| 0:20–0:40 | Рабочий React tutorial, около 8 секунд ожидания, реальная оценка | «Контекст важнее домена. На YouTube тоже можно работать. При нехватке данных AI это признаёт.» |
| 0:40–1:00 | Развлекательный материал на том же домене, оценка и причина. Кнопка возврата | «Напоминание даёт выбор. Вкладка не закрывается, данные не теряются.» |
| 1:00–1:15 | Поправка «Это по делу» или короткое включение строгого режима | «Я могу исправить ошибку; поправка относится к этому контексту, не ко всему сайту. Сеанс можно остановить всегда.» |
| 1:15–1:30 | Подтвердить последний шаг, начать перерыв, вручную продолжить; объяснить карточку по окончании | «Расширение хранит подтверждённый шаг и рабочие материалы. Оно не утверждает, что я всё прочитал.» |
| 1:30–1:45 | Редактор задачи из выделения либо предварительный просмотр групп, подтверждение | «AI предлагает. Сохраняю и применяю я. Это настоящие группы Chrome.» |
| 1:45–2:00 | Завершение, реальные интервалы статистики, EN, настройки приватности | «Мы показываем события, а не вымышленную продуктивность. Ключ хранится на локальном сервере.» |

Для воспроизводимой записи без оплаченного API допустимо показать результаты `test:browser` только с явной подписью «тестовый ответ». Не выдавайте fixture классификацию за настоящий ответ DeepSeek. Перерыв в демо не нужно ждать пять минут: покажите запуск/ручное продолжение, а автоматическую карточку — отдельным заранее завершённым перерывом.
